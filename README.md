# Python Backend Masterclass 🚀

Bu depo, Python backend geliştirme becerilerini sıfırdan ileri seviyeye taşıyan 10 projeyi içermektedir. Basit CRUD işlemlerinden başlayıp, N-Katmanlı mimariler, Clean Architecture, asenkron işlemler ve mikroservislere kadar uzanan profesyonel bir yolculuğu temsil eder.

## Projeler

### 1. Portfolio API (Temel CRUD)
* **Durum:** Geliştirme Aşamasında 🚧
* **Teknolojiler:** FastAPI, SQLite
* **Açıklama:** Yönlendirme (routing), CRUD işlemleri ve temel API tasarımını kavramak için oluşturulmuş, tek katmanlı (Monolitik) kişisel portfolyo yönetim API'si.
